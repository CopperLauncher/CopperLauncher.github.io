Information About Renderers

Holy GL4ES

  • Simple Engine, Best Performance;
  • Little Compatibility with Mods & Shaders;
  • Cannot Run Minecraft 1.21.6+.

LTW

  • Almost as fast as GL4ES;
  • Good Compatibility with lots of mods & shaders;
  • Heals Skin Cancer;
  • Supports Minecraft 1.17- Latest.

Zink

  • Very Good Compatibility with almost all Shaders & Mods;
  • Very Slow;
  • Supports Minecraft 1.0- 1.21.5.

Krypton Wrapper

  • Capability to Handle More Advanced Shaders;
  • Capability to Run Minecraft in Almost all Versions;
  • More Advanced OpenGL Features;
  • Run Sodium in Minecraft 1.16.5;
  • Supports Minecraft 1.0- Latest.

MobileGlues

  • Almost as fast as GL4ES;
  • Good Compatibility with lots of Mods like Sodium & Some Shaders;
  • Heals Skin Cancer;
  • Supports Minecraft 1.17- Latest.

Alternate Surface Renderer

In order to render stuff for the user to see, you need some sort of window. On Android, a "window" is a producer-consumer pair (where the producer is the OpenGL driver that Minecraft runs on).

The "Alternate Surface Renderer" changes who's the consumer.

Off: The consumer is surfaceflinger (the system compositor) which means stricter timings are enforced. This means that stutters practically disappear if your device is good enough.

On: The consumer is a TextureView, which renders the buffer using the standard view system. This is a worse approach, because it reduces the amount of synchronization done when redering, which means stutters for powerful devices. However, less synchronization also means higher FPS numbers.
